Generador de paletas

Colorfly Studio

¿Cómo usar el generador?
  1. Elige la cantidad de colores (6, 8 o 9) y el formato de código (HEX o HSL).
  2. Presiona Generar paleta para crear colores nuevos.
  3. Cambia el formato cuando quieras: los colores no cambian, solo el código.
  4. Haz clic en el código de un color para copiarlo.
  5. Presiona Anclar en un color para conservarlo: los demás se generarán con una gama de colores armónica.
  6. Presiona Guardar paleta para enviarla al historial. Desde ahí puedes cargarla o eliminarla.
